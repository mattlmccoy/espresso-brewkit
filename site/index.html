Brewkit

Measurement tools for espresso. Log shots, propagate uncertainty, and find which variables move extraction yield.

01

Calculator

Brix to TDS to extraction yield, brew ratio, solids in the cup, average flow.

 02

Shot log

Record shots and export one CSV. Reads the old one-file-per-shot format too.

Explore

Regression against one variable or two, with confidence bands and a rotatable plane fit.

 04

Quality

Outlier detection by three methods, plus the repeatability statistics behind them.

 05

Uncertainty

GUM propagation through the yield equation, with a variance budget.

Scale design

Hardware and firmware spec for a scale that logs shots on-device.
Sample data

Load 15 real extractions to see every tool populated. Clear them whenever you want to start your own log.

Storage

Shots live in this browser's local storage. Nothing is uploaded, there is no account, and the export is a plain CSV you own.

The same schema is what the scale writes to its own flash.
