An empty log

This log starts empty on purpose. There used to be a button here that loaded fifteen shots from the project's Python era into it — but those were pulled on entirely different equipment, and mixed into your log they skew the grind model, the habit calendar and every comparison.

They still exist, in the one place they are useful: the Lab loads them as a reference set, because they carry Brix on every row and the analysis tools need something to analyse.

Storage

Shots live in this browser and stay there — closing the tab, quitting the browser and shutting the computer down all leave the log where it was. Nothing is uploaded and there is no account.

Clearing site data would take it with them, so Backup writes the lot to a file you keep. The same schema is what the scale writes to its own flash.
