Where your shots actually live

In this browser, on this computer. Not in a session — closing the tab, quitting the browser and shutting the machine down all leave the log exactly where it was. It is keyed to this browser on this profile, so Chrome and Firefox on the same machine keep separate logs, and so does a private window.

Nothing is uploaded, ever. There is no account and no server. That also means there is no copy anywhere else, which is what this page is for: clearing site data, or telling the browser to wipe everything on exit, takes the log with it.

The file is plain JSON. Readable, diffable, and yours. The shot rows inside it are the same schema the scale writes to its own flash, and Shots will export the same rows as CSV if you would rather work with them in a spreadsheet.

Two devices

Merging, not overwriting. Shots are unioned by id, so pulling shots on the laptop and rating them on the phone loses neither. When the same shot exists on both sides, the one edited later wins. Deletions travel too, as tombstones — without them a union could only ever add, and a shot deleted here would come straight back from the other device's file.

To watch a pour live, don't use this page. A file is the wrong shape for a number that moves ten times a second. Watch takes the frames straight off the laptop over your own network — no account, no server, nothing leaving the room. Start it from Watch on phone on the Live page.

On an iPhone or iPad this is a viewer and a logger. No iOS browser has Web Bluetooth — not Safari, and not Chrome, which is Safari underneath — so a phone cannot stream the scale. It can read your shots and curves, rate a shot, and enter weights by hand. Scale streaming stays on the computer; that is Apple's decision rather than something this project can work around.
