Scale not listed? A BLE device stops advertising while something else is connected to it — close nRF Connect, the vendor app, or another tab holding it. Many scales also sleep after a minute or two idle.

Chrome, Edge and Opera only. Firefox and Safari have no Web Bluetooth, and on iOS no browser does. Without a scale the session still works — every weight becomes something you type instead of something that arrives.

Set up this scale

This scale sends an unlabelled frame, so brewkit needs to learn where the weight sits. Put a known mass on, type what the scale's own display reads, and capture. Three at different masses is plenty — include zero.

Somebody already worked this scale out? A profile is the answer to the teaching step, in a file. Import one and this is done — no reference masses needed.

Tap sensitivity

Scales differ enormously in what a tap looks like: they sample ten times a second and smooth internally, so the same finger can read as 40 g on one and 4 g on another. Tap the platter and this shows what yours actually reports.

—

Exporting gives you a small JSON file describing how this scale encodes weight. Anyone with the same model can import it and skip the teaching step entirely \u2014 which is how this supports scales nobody here has ever held.

Re-validating reopens the setup step so you can capture fresh reference masses — useful if readings drift or you swapped scales. Your existing captures are kept.
