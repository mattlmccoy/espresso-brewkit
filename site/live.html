Set up this scale

This scale sends an unlabelled frame, so brewkit needs to learn where the weight sits. Put a known mass on, type what the scale's own display reads, and capture. Three at different masses is plenty — include zero.

Somebody already worked this scale out? A profile is the answer to the teaching step, in a file. Import one and this is done — no reference masses needed.
